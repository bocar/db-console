# db-console 项目需求

## 1. 范围

首版提供浏览器数据库工作台。技术栈和部署方式见 [README](../README.md)。

首批验收 MySQL 和达梦 DM8。Oracle、SQL Server、TiDB 和 OceanBase 保留为适配目标，具备测试条件后再验收。OceanBase 的 MySQL 和 Oracle 租户模式分别验证。

## 2. 功能与验收条件

### 登录与数据源

- **F-01 登录**　使用应用配置文件中的单个账号登录。业务库不可达时仍可验证登录。凭据错误时拒绝登录。未登录、退出或会话失效后，连接测试、结构读取和 SQL 执行均不可用。
- **F-02 数据源**　显示当前数据源、环境、数据库类型和可用的库或模式。浏览器只传数据源标识，后端从配置读取连接信息。连接测试区分认证失败和连接超时，错误信息不暴露凭据。未知标识须被拒绝。使用已有驱动的新增数据源在重启后可用。

### 对象树与编辑器

- **F-03 对象树**　按数据源、库或模式、表组织，支持查找、展开、折叠和刷新。显示表列注释、列类型、可空性、默认值和主键，显示索引名称、唯一性及列顺序，显示外键约束名及本表列与引用表列的对应关系。优先读取 JDBC 元数据，缺失时按方言补查。支持将正确引用的表名或列名插入编辑器。验收覆盖限定名、混合大小写、复合索引和复合外键。切换数据源时清除旧对象和旧结果，忽略迟到的旧请求响应。建表或删表生效后刷新表列表，改表或修改注释生效后刷新对应表。
- **F-04 编辑器**　提供高亮、执行按钮、快捷键和清空。有选区时执行选区，否则执行全文。后端按方言只接受一条语句或客户端命令，拒绝空白、纯注释和多语句输入。允许单个末尾分号，忽略字符串、引用标识符及注释中的分号。
- **F-05 SQL 范围**　执行目标库原生的 `SELECT`、`INSERT`、`UPDATE`、`DELETE` 及其支持的 `WITH` 形式。表级 DDL 包括 `CREATE TABLE`、`ALTER TABLE`、`DROP TABLE` 和 F-07 的表列注释。后端拒绝超出范围的操作，并按 CTE 的实际操作应用确认和权限规则。
- **F-06 表结构命令**　`DESC` / `DESCRIBE` 与对象树共用表结构查询。裸表名按当前库或模式解析，也支持按方言限定的表名。查询返回与对象树一致的列信息，失败时显示目标表及可用的错误信息。
- **F-07 表列注释**　对象树可生成当前方言的新增和修改语句。MySQL、TiDB 和 OceanBase MySQL 模式使用 `COMMENT` 子句。Oracle、DM8 和 OceanBase Oracle 模式使用 `COMMENT ON`。SQL Server 使用 `MS_Description` 扩展属性并区分新增与更新。修改注释须保留原有类型、默认值和约束，确认与提交规则见 F-09 和 F-16。

### 确认与事务

**F-09 执行确认**　执行区显示目标环境和事务状态。对需要二次确认的操作，后端将确认与当前会话、数据源和 SQL 文本绑定，缺少有效确认时拒绝执行。SQL 权限由数据库账号决定，验收时验证只读账号无法写入。

**F-16 提交与回滚**　按目标数据库版本、配置和实际语句判断 DDL 的提交方式。

| 操作 | 执行前二次确认 | 提交方式 |
| --- | --- | --- |
| 数据增删改，含 CTE 写入 | 生产环境全部确认。其他环境仅确认最外层没有 `WHERE` 的更新或删除。 | 手动提交或回滚 |
| 可事务化的 DDL | 各环境均无需确认 | 手动提交或回滚 |
| 会触发隐式提交的 DDL | 各环境均须确认，并提示生效及回滚限制。 | 确认后在独立连接上执行，成功即生效。 |

- 手动事务关闭自动提交，同一会话和数据源绑定同一事务连接，可逐条执行多条 SQL。执行成功后显示「未提交」。「提交（Commit）」和「回滚（Rollback）」作用于整个事务。其他登录会话无法操作该事务。非事务表写入无法保证手动提交时，在执行前拒绝并说明原因。
- 切换数据源或执行隐式提交 DDL 前，用户须先结束已有未提交事务。退出、会话失效或事务空闲超时时，回滚未提交事务并释放连接。
- MySQL、DM8 和 Oracle 的常规建表、改表、删表会触发隐式提交，实际行为按目标库和语句验收。 [MySQL 隐式提交](https://dev.mysql.com/doc/refman/8.4/en/implicit-commit.html)、[达梦事务管理](https://eco.dameng.com/document/dm/zh-cn/pm/management-affairs.html)、[Oracle COMMIT](https://docs.oracle.com/en/database/oracle/oracle-database/19/sqlrf/COMMIT.html)

### 结果、历史与审计

- **F-08 结果与错误**　查询显示列名、结果行和耗时，零行时保留列名。结果按列位置传输，保留重名列及大整数、高精度小数的精度。按驱动返回值区分 SQL `NULL` 与空字符串。变更操作显示状态和受影响行数，驱动未提供行数时明确标注。按页限制返回行数和结果体积，并限制单元格大小。有下一页和当前页内容被截断分别提示。数据库错误须可定位，响应不暴露内部堆栈或凭据。
- **F-10 限制与审计**　限制 SQL 长度、执行时间和并发，超限时明确反馈。写入或提交超时、连接中断且无法确认状态时，显示「执行结果未知」。系统不自动重试写入或提交。执行、提交和回滚分别写入审计文件，记录操作者、数据源、时间、耗时和状态。审计文件和应用日志不记录凭据、完整 SQL 或结果数据。
- **F-11 分页**　查询结果由后端按目标库方言分页取数。支持上一页、下一页和调整每页行数，后端返回当前页和是否还有下一页。可取得总行数时显示总行数和总页数，并支持指定页码。翻页使用原查询、数据源及事务上下文，可读取超过单次返回上限的后续行。重新执行、切换数据源或修改每页行数时重置到第一页。分页仅适用于只读查询，不能通过翻页再次执行写入或 DDL。
- **F-12 历史**　当前登录会话内按数据源查看、清空近期 SQL。载入历史只填充编辑器。退出或会话失效时清除历史。
- **F-14 查询取消**　可取消当前会话的指定运行中查询。请求发出后显示「取消中」，最终显示实际结果。若查询先完成，保留结果。取消失败时提示原因。
- **F-15 导出与复制**　将本次查询已加载的结果和列名导出为 UTF-8 CSV，提示导出范围和内容截断。可复制选中的单元格或行。导出和复制无需重新执行 SQL。验收覆盖中文、逗号、引号、换行及选区一致性。

### 扩展功能

- **F-13 脚本执行**　独立入口支持导入和预览语句顺序、目标环境及提交方式。执行前按方言校验边界和操作范围，校验失败时整份脚本不执行。执行中途失败即停止，报告条次、执行状态和写入语句的提交状态。确认续跑位置后才从指定条次继续。结果未知时先核实数据库状态。

## 3. 配置与交付

- 应用配置管理服务地址、端口、单个登录账号、日志和执行限制。数据源配置包含唯一标识、显示名、环境、数据库类型、兼容模式、JDBC URL、数据库账号和凭据引用，数据库密码通过环境变量注入。
- 启动时校验登录配置、数据源标识唯一性、类型、模式、驱动、凭据引用和执行限制。配置无效时启动失败并说明原因。数据库连通性和认证在连接测试或首次使用时检查，某个业务库不可达时其余可达数据源仍可使用。配置通过重启生效。
- 同版本交付可执行 JAR 和 Docker 镜像。页面资源随 JAR 分发，无需访问 CDN。容器挂载外部配置和审计目录。驱动版本随发行版锁定，允许再分发的驱动随包交付，其余由部署方提供。DM8 驱动优先选择与服务端版本接近的版本，并在 Java 17 上验证。

### 待定参数

- 默认值待定，部署时可通过外部配置调整。涉及查询超时、事务空闲超时、返回行数和体积上限、执行并发、会话有效期及审计保留期。
- MySQL 和 DM8 的具体版本与测试实例在首批验收前确定。

## 4. 开发规范

- **Java**　格式按 Google Java Style，包括 UTF-8、两空格缩进和显式导入。异常、日志、测试和安全实践参考阿里巴巴 Java 开发手册。格式冲突时以 Google Java Style 为准。 [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html)、[阿里巴巴 Java 开发手册](https://github.com/alibaba/p3c)
- **后端分工**　按功能分包。Controller 校验请求并返回响应，服务层负责登录和执行流程，JDBC 层管理资源，方言层处理厂商差异。使用构造器注入和明确的请求、响应类型。元数据查询优先参数绑定，对象标识符按方言解析和引用。JDBC 资源用 try-with-resources 关闭，异常保留原因，日志脱敏，测试凭据使用占位值。
- **Vue**　使用单文件组件、Composition API 和 `<script setup lang="ts">`，启用 TypeScript 严格检查，显式声明组件属性、事件和 API 数据类型。组件名称使用可读的多词名称。集中维护请求和共用状态逻辑，区分加载、空结果、错误和会话失效。SQL、注释、结果和数据库错误按文本渲染。 [Vue TypeScript 指南](https://vuejs.org/guide/typescript/overview.html)、[Vue 风格指南](https://vuejs.org/style-guide/)、[Vue 测试指南](https://vuejs.org/guide/scaling-up/testing.html)
- **构建检查**　锁定依赖版本，后端在 Java 17 下运行格式检查和测试。前端运行格式检查、ESLint、类型检查和测试。

## 5. 发布验收

1. **自动化检查**　后端覆盖语句边界、方言分派、错误映射、结果限制，以及登录、数据源标识校验、确认、事务、取消和审计。前端覆盖选区执行、切换数据源、结果处理、历史载入和执行确认。
2. **数据库验收**　用隔离的 MySQL 和 DM8 实例逐项验证适用的首版功能，生产确认使用标记为生产的测试数据源验证。用独立连接验证提交前后可见性、整笔事务回滚和会话失效清理。验证隐式提交 DDL 在有未提交事务时被拦截，在二次确认后单独生效并刷新对象树。后续验收支持事务化 DDL 的目标库时，验证各环境均可直接执行，再手动提交或回滚。用可控长查询验证取消成功及查询先完成两种情况。启用 TLS 时验证握手。
3. **交付验收**　分别启动 JAR 和 Docker 镜像，验证无需应用库即可启动和登录。接入测试业务库后验证连接与 SQL 执行。重启后验证外部配置生效、审计文件可读。

发布时记录数据库版本、JDBC 驱动版本、JDK、兼容模式及验证结果。目标方言原生不支持的操作标记为不适用并说明原因。

分页验收使用排序明确且超过单页上限的固定结果，验证 MySQL 和 DM8 能连续取到后续页，前后翻页无重漏，末页正确禁用下一页，切换页大小或数据源后重置。写操作执行后不显示分页入口。
